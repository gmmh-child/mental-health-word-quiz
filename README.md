# 정신건강 가로세로 낱말퀴즈

정적 HTML로 만든 가로세로 낱말퀴즈입니다. 별도의 빌드 과정이나 서버가 필요하지 않습니다.

## GitHub Pages 배포 방법

1. GitHub에서 새 저장소(repository)를 만듭니다.
2. 이 폴더 안의 `index.html`과 `README.md`를 저장소 최상위(root)에 올립니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Build and deployment**에서 `Deploy from a branch`를 선택합니다.
5. Branch는 `main`, 폴더는 `/(root)`로 선택한 뒤 **Save**를 누릅니다.
6. 잠시 기다린 후 Pages 화면에 표시되는 사이트 주소를 엽니다.

## 수정 방법

퀴즈 내용을 바꾸려면 `index.html`을 수정한 뒤 저장소에 다시 커밋하면 됩니다. GitHub Pages가 변경 사항을 자동으로 배포합니다.
