# 정신건강 가로세로 낱말퀴즈 — GitHub Pages 배포용

## 변경 사항
- 참여자 화면에서 `응답 CSV 내려받기` 버튼을 제거했습니다.
- 공개 HTML에서 해당 CSV 다운로드 기능 코드도 제거했습니다.
- 퀴즈 응답은 기존에 설정된 Google Apps Script URL로 전송되도록 유지했습니다.

## 응답 CSV 다운로드 방법(관리자)
1. 관리자 Google 계정으로 응답이 저장되는 Google 스프레드시트를 엽니다.
2. `파일` → `다운로드` → `쉼표로 구분된 값(.csv)`을 선택합니다.
3. 스프레드시트 공유 설정은 관리자만 접근할 수 있도록 제한하세요.

참고: 공개 웹페이지 안에 비밀번호로 숨긴 관리자 버튼을 두는 방식은 소스 코드 확인 등으로 우회할 수 있어 보안상 안전하지 않습니다. 그래서 공개 퀴즈 페이지에서는 다운로드 기능을 제거하고, 관리자 계정으로 스프레드시트에서 내려받도록 구성했습니다.
